## 🎯 درباره پروژه

این پروژه از دل چالش‌های واقعی دانشجویی متولد شد. از سردرگمی در انتخاب واحد و جستجوی نظرات درباره اساتید در گروه‌های شلوغ تلگرامی، تا فراموش کردن ددلاین‌ها و رزرو غذا — ما با این دغدغه‌ها یک سوال مشترک داشتیم: **چرا یک سامانه‌ی هوشمند، ساده و یکپارچه برای کمک به دانشجویان وجود ندارد؟**

این سامانه تلاشی است برای پاسخ به این سوال. ما یک پلتفرم متمرکز ساخته‌ایم که ابزارهای مختلفی را برای تسهیل زندگی آکادمیک در اختیار دانشجویان قرار می‌دهد.

<br />

## ✨ ویژگی‌های کلیدی

این سامانه از چند ماژول اصلی تشکیل شده است:

#### 📅 **برنامه‌ریز هوشمند انتخاب واحد**

- **وارد کردن دروس از گلستان**: خزنده‌های ما اطلاعات دروس را مستقیماً از سامانه گلستان دریافت می‌کنند.
- **ساخت چند سناریو**: چندین برنامه درسی مختلف بسازید، مقایسه کنید و بهترین را انتخاب کنید.
- **تشخیص تداخل**: هشدارهای هوشمند برای تداخل زمانی کلاس‌ها و امتحانات.
- **ذخیره و اشتراک‌گذاری**: برنامه‌های خود را ذخیره کنید یا به صورت PDF خروجی بگیرید و با دوستانتان به اشتراک بگذارید.

#### ⭐️ **سامانه نظرات اساتید و دروس**

- **پایگاه داده نظرات**: دیگر نیازی به جستجو در گروه‌های تلگرامی نیست! نظرات دانشجویان درباره اساتید و دروس را در یک محیط با UI/UX بهینه مشاهده و ثبت کنید.
- **جستجوی آسان**: به راحتی استاد یا درس مورد نظر خود را پیدا کنید.

#### 🔔 **سیستم اطلاع‌رسانی هوشمند**

- **یادآوری ددلاین‌ها**: یادآوری مهلت ارسال تمرین‌های LMS.
- **یادآوری‌های دانشگاهی**: فراموشی رزرو غذا یا تاریخ حذف و اضافه دیگر معنایی ندارد!
- **ارسال از طریق ایمیل و پیامک**: اطلاعیه‌های مهم را روی کانال دلخواه خود دریافت کنید.

#### 🤖 **چت‌بات هوشمند**

- **پاسخ به سوالات متداول**: دریافت پاسخ سوالات رایج درباره قوانین دانشگاه و فرآیندها.
- **پیشنهاد استاد**: بر اساس معیارهای شما، بهترین اساتید را پیشنهاد می‌دهد.
- **تبدیل صوت به جزوه**: فایل‌های صوتی ضبط شده در کلاس را به متن تبدیل می‌کند.

## 🛠️ پشته فناوری (Technology Stack)

این پروژه با استفاده از ابزارها و تکنولوژی‌های زیر ساخته شده است:

| بخش                  | تکنولوژی                                                                                                  |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| **Backend**          | [Django](https://www.djangoproject.com/), [Django REST Framework](https://www.django-rest-framework.org/) |
| **Database**         | [PostgreSQL](https://www.postgresql.org/)                                                                 |
| **Containerization** | [Docker](https://www.docker.com/), Docker Compose                                                         |
| **Testing**          | [Pytest](https://pytest.org/)                                                                             |
| **API Docs**         | [DRF Spectacular](https://drf-spectacular.readthedocs.io/) (Swagger & ReDoc)                              |
| **Authentication**   | Token-based (JWT)                                                                                         |
| **Localization**     | پشتیبانی دو زبانه (فارسی و انگلیسی) بر اساس هدر `Accept-Language`                                         |

## 🚀 نصب و راه‌اندازی (محیط توسعه)

برای اجرای پروژه به صورت محلی، مراحل زیر را دنبال کنید. (پیش‌نیاز: [Docker](https://www.docker.com/get-started) و [Docker Compose](https://docs.docker.com/compose/install/) باید نصب باشد)

۱.  **پروژه را کلون کنید:**

```bash
git clone https://github.com/Yonesj/unico-backend.git
cd unico-backend
```

۲.  **پروژه را با Docker Compose اجرا کنید:**

```bash
docker-compose -f docker-compose.development up --build
```


تمام!  این دستور کانتینرهای دیتابیس و وب را ساخته، به صورت خودکار مایگریشن‌ها را اجرا کرده، کاربر ادمین را می‌سازد و داده‌های اولیه را بارگذاری می‌کند. حالا پروژه روی آدرس `http://localhost:8000` در حال اجراست.

## 🏛️ معماری کلی و ساختار پوشه‌ها

سامانه‌ی **Unico** به صورت ماژولار (App-based) طراحی شده و هر ماژول (اپلیکیشن) به وظایف مشخصی اختصاص دارد. ساختار پوشه‌ها به شکل زیر است:

```
src/
├── accounts/          # کاربران، احراز هویت و مدیریت پروفایل
├── courses/           # برنامه‌ریز انتخاب واحد و تعامل با سیستم گلستان
├── crawlers/          # خزنده‌ها (از جمله حل‌کننده‌ی کپچا)
├── notifications/     # ارسال و مدیریت نوتیفیکیشن‌ها
├── reviews/           # ثبت، مدیریت و واکنش به نظرات اساتید و دروس
├── tickets/           # سیستم تیکتینگ (پشتیبانی)
├── utill/             # ابزارها و کمک‌کننده‌های عمومی (utils)
└── ...
```

## 👑 پنل مدیریت (Admin Panel)

برای مدیریت آسان داده‌ها، تمامی مدل‌های پروژه (مانند کاربران، دروس، نظرات و ...) در پنل ادمین جنگو ثبت شده‌اند. این پنل به شما اجازه می‌دهد به راحتی داده‌های سامانه را مشاهده، ایجاد یا ویرایش کنید.

هنگام اجرای پروژه با `docker-compose`, یک کاربر ادمین (superuser) به صورت **خودکار** برای شما ساخته می‌شود.

- **آدرس پنل ادمین:** `http://localhost:8000/admin/`
- **ایمیل:** `admin@gmail.com`
- **رمز عبور:** `admin`

<br />

## 💡 مستندات API

مستندات کامل API به صورت خودکار با استفاده از `drf-spectacular` تولید شده است. پس از اجرای پروژه، می‌توانید از آدرس‌های زیر به آن دسترسی پیدا کنید:

- **Swagger UI:** `http://localhost:8000/api/docs/`
- **ReDoc:** `http://localhost:8000/api/redoc/`

<br />

## 🧪 اجرای تست‌ها

ما برای اطمینان از صحت عملکرد کد، از `pytest` برای نوشتن Unit Test استفاده می‌کنیم. برای اجرای تست‌ها، دستور زیر را وارد کنید:

```bash
docker-compose -f docker-compose.development exec web pytest
```
